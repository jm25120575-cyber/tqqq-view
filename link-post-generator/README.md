# 링크 게시글 생성기

링크를 넣으면 그 페이지의 제목·요약·본문을 가져와, 붙여넣은 예시 글 틀에 채워 게시판용 제목과 본문을 만든다. 게시판에 자동 등록하지는 않는다(reCAPTCHA가 있어서). 결과 칸의 복사 버튼으로 복사해 붙여넣는다.

## 실행

```bash
cd link-post-generator
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 열린다.

## 사용법

1. 링크를 넣고 **가져오기**를 누른다.
2. **예시 글** 칸에 예시 글을 붙여넣고, 링크 내용이 들어갈 자리를 아래 자리표시자로 바꾼다. 비워 두면 기본 틀(직접 쓴 내용 + 발췌 + 출처)을 쓴다.
3. **직접 쓸 내용** 칸에 쓴 글은 `{my_text}` 자리에 들어간다.
4. **예시 글·제목 틀 저장**을 누르면 `template.json`에 저장돼 다음 실행 때도 불러온다.

| 자리표시자 | 들어가는 내용 |
|---|---|
| `{title}` | 페이지 제목 |
| `{description}` | 페이지 요약(메타 설명) |
| `{site_name}` | 사이트 이름 |
| `{url}` | 원문 링크 |
| `{image}` | 대표 이미지 주소 |
| `{excerpt}` | 본문 발췌(사이드바의 발췌 길이만큼) |
| `{my_text}` | 직접 쓴 내용 |

예시:

```
오늘 본 기사 공유합니다.

[{title}]
{excerpt}

제 생각: {my_text}

원문: {url}
```

## 한계

- 로그인이 필요한 페이지나 자바스크립트로 본문을 그리는 페이지는 본문을 못 가져올 수 있다.
- 네이버 블로그는 내부 iframe을 따라가서 읽는다.
