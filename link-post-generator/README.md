# 링크 게시글 생성기

링크를 넣으면 그 페이지의 제목과 본문을 가져와, 붙여넣은 예시 글에 채워 게시판용 제목과 본문을 만들어 주는 윈도우 프로그램.

## 받기

[다운로드 페이지](https://github.com/jm25120575-cyber/tqqq-view/releases/tag/link-post-generator)에서 `LinkPostGenerator.exe`를 받아 더블클릭한다. 설치는 필요 없다.

처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누른다.

## 쓰는 법

1. **① 링크**에 주소를 붙여넣고 **가져오기**를 누른다.
2. **② 예시 글**에 예시 글을 붙여넣는다. 링크 내용이 들어갈 자리에 커서를 두고 `+ 제목`, `+ 본문 발췌` 같은 버튼을 누르면 그 자리에 `{제목}`, `{발췌}`가 들어간다. 비워 두면 기본 틀(내가 쓴 글 + 발췌 + 출처)을 쓴다.
3. **③ 내가 쓸 내용**에 쓴 글은 예시 글의 `{내글}` 자리에 들어간다.
4. **④ 결과**의 **제목 복사**, **본문 복사**를 눌러 게시판에 붙여넣는다.

**예시 글 저장**을 누르면 다음에 켤 때도 예시 글이 그대로 남아 있다.

## 한계

- 로그인이 필요한 페이지나 자바스크립트로 본문을 그리는 페이지는 본문을 못 가져올 수 있다.
- 게시판에 자동으로 올리지는 않는다(게시판에 reCAPTCHA가 있음).

## 개발

`link-post-generator/` 아래 파일을 고쳐 push하면 GitHub Actions가 exe를 다시 빌드해 다운로드 페이지에 올린다.
