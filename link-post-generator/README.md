# 게시판 자동 글올리기

올릴 글 목록을 만들어 두고 **올리기 시작**을 누르면, 크롬(없으면 엣지)을 띄워 자동 로그인하고 제목·본문을 넣고 등록까지 하는 윈도우 프로그램. "로봇이 아닙니다" 체크만 사람이 직접 누른다.

## 받기

[다운로드 페이지](https://github.com/jm25120575-cyber/tqqq-view/releases/tag/link-post-generator)에서 `LinkPostGenerator.exe`를 받아 더블클릭한다. 설치는 필요 없다.

처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누른다.

## 쓰는 법

1. **① 설정**에 글쓰기 주소, 아이디, 비밀번호를 넣고 **설정 저장**을 누른다. 글쓰기 주소가 바뀌면 이 칸만 고치면 된다.
2. **② 올릴 글**에서 **새 글**을 누르고 오른쪽에 제목과 본문을 쓴다. 고친 내용은 바로 저장된다.
   - 여러 개를 한 번에 넣으려면 **파일에서 불러오기**를 쓴다. 텍스트 파일에서 글마다 첫 줄이 제목, 나머지가 본문이고, 글 사이에 `===`만 있는 줄을 넣는다.
3. **③ 올리기**에서 **올리기 시작**을 누른다. 브라우저가 열리고 제목·본문이 채워지면 **"로봇이 아닙니다"만 직접 체크**한다. 체크하면 프로그램이 등록 버튼을 누르고, 정해 둔 간격만큼 기다렸다가 다음 글로 넘어간다.
4. 올린 글은 상태가 **완료**로 바뀌고, 다시 시작해도 완료된 글은 건너뛴다.

## 알아둘 것

- **글 사이 간격**: 기본 60초. 사이트가 "너무 빠른 시간내에 게시물을 연속해서 올릴 수 없습니다"를 띄우면 그 글은 실패로 표시되고, 2번 연속 실패하면 멈춘다. 이때 간격을 늘리고 다시 시작하면 실패한 글부터 올린다.
- 사이트 접속 시 Cloudflare 보안 확인 화면이 뜨면 직접 눌러 준다. 프로그램은 그동안 기다린다.
- 브라우저 로그인 상태는 프로그램 전용 프로필에 남아서, 한 번 로그인하면 다음부터는 로그인 과정을 건너뛴다.
- 설정과 글 목록은 `%APPDATA%\LinkPostGenerator`에 저장된다. 비밀번호는 윈도우 암호화(DPAPI)로 저장돼 이 PC의 이 계정에서만 풀린다.
- 제목·본문 칸과 등록 버튼은 이름(`wr_subject`, `wr_content`, `btn_submit` 등)과 글자("작성완료", "등록")로 찾는다. 다른 사이트로 바꿔서 칸을 못 찾으면 로그에 그렇게 나온다.

## 개발

`link-post-generator/` 아래 파일을 고쳐 push하면 GitHub Actions가 exe를 빌드하고, 브라우저가 열리는지 확인한 뒤 다운로드 페이지에 올린다.
