# BMW 530i (G30, 2019년식) 커스텀·코딩 정리

현대 쏘나타 DN8에서 하는 "네메시스 적용"은 헤드유닛 소프트웨어를 바꿔 기능을 여는 방식이다. BMW는 같은 일을 **코딩**(차량 모듈 설정값 변경)과 **FSC 활성화**(BMW가 막아둔 기능 키를 여는 것)로 한다. G30은 코딩으로 열 수 있는 항목이 많은 편이다.

## 0. 먼저 확인할 것: 헤드유닛 종류

2019년식 G30은 생산 시기와 옵션에 따라 헤드유닛이 둘 중 하나다. 무엇이 가능한지가 여기서 갈린다.

| 구분 | NBT EVO (iDrive 6) | MGU (iDrive 7, Live Cockpit Professional) |
|---|---|---|
| 계기판 | 아날로그 바늘 + 중앙 LCD | 전체 디지털 계기판 |
| iDrive 메뉴 | 가로 타일형 | 위젯형 메인화면 |
| 무선 애플 카플레이 | 기본 지원 또는 FSC 활성화로 가능 | 기본 지원 |
| 안드로이드 오토 | 순정 미지원 → 별도 모듈/활성화 필요 | 소프트웨어 업데이트(2020년 이후 버전)로 무선 AA 지원 |

확인 방법: iDrive → 설정(My Vehicle) → 시스템 정보 / 소프트웨어 버전. 계기판이 바늘식이면 거의 NBT EVO다.

**현재 차량 상태**: 안드로이드 오토가 안 돼서 NBT EVO(iDrive 6)로 추정. 단, iDrive 7(MGU)도 소프트웨어가 2020년 이전 버전이면 AA가 없으므로 계기판 모양으로 한 번 더 확인한다. 아래 내용은 NBT EVO 기준으로 우선 정리했다.

## 1. 안드로이드 오토 / 카플레이

- **MGU(iDrive 7)**: 순정 소프트웨어가 오래된 버전이면 AA 메뉴가 없다. BMW 서비스센터나 ISTA로 I-Step 업데이트를 하면 무선 AA가 생긴다. 업데이트 후 카플레이/AA 활성화가 안 돼 있으면 코딩으로 켠다.
- **NBT EVO(iDrive 6)**: 순정으로는 AA가 없다. 방법은 두 가지다.
  - 소프트웨어 활성화 업체(예: Bimmer-tech 등)의 NBT EVO용 AA 활성화
  - 외부 MMI 인터페이스 박스(유선 AA 신호를 받아 순정 화면에 띄우는 방식)
  - 비교 포인트: 소프트웨어 활성화는 추가 장비가 없어 깔끔하지만 센터 업데이트 때 풀릴 수 있다. MMI 박스는 업데이트 영향은 적지만 대시보드 안에 장비를 설치해야 하고, 무선으로 쓰려면 무선 지원 제품인지 확인해야 한다.
  - 시공 전 업체에 "NBT EVO 소프트웨어 버전(ID5/ID6)"과 "무선 AA 지원 여부"를 같이 물어본다.
- 카플레이가 꺼져 있는 차량은 FSC 코드 생성 툴로 활성화한다. 이때 FSC 원본 백업을 반드시 해둔다.

## 2. BimmerCode로 많이 하는 코딩 항목

BimmerCode 앱 + OBD 어댑터(ENET 케이블 또는 지원 Wi-Fi/BT 어댑터)로 대부분 가능하다. 앱이 차량 모듈을 자동 인식하므로 실제 가능 항목은 앱에서 확인한다.

**주행 중 영상(Video in Motion)**
- 주행 중에도 iDrive에서 영상 재생, 메뉴 입력 가능

**편의**
- 오토 스타트/스톱 마지막 상태 기억 (시동 걸 때마다 끄지 않아도 됨)
- 잠금 시 사이드미러 자동 접힘 / 리모컨으로 창문 전체 열기·닫기(컴포트 오픈/클로즈)
- 오토홀드 상태 기억
- 안전벨트 경고음 끄기
- 시동 끈 후 오디오 계속 재생

**계기판/화면**
- 디지털 속도계 표시
- 스포츠 디스플레이(출력·토크 게이지) 활성화
- 시동 시 M 로고 / 계기판 테마 변경 (MGU 계기판에서 가능 범위가 넓음)
- 후방카메라 화면에서 주차 가이드라인 상시 표시

**조명**
- 데이라이트(엔젤아이) 밝기 조정
- 웰컴 라이트 / 코너링 라이트 설정
- 방향지시등 원터치 점멸 횟수 변경(3회 → 5회 등)

**기타**
- 문 잠금 시 경적 확인음
- 트렁크 전동 개폐 높이 메모리
- 계기판 경고 메시지 일부 비활성화

## 3. 툴 선택

| 툴 | 난이도 | 비용 | 비고 |
|---|---|---|---|
| BimmerCode | 쉬움 | 앱 유료 + 어댑터 | 메뉴 선택식. 처음 하는 사람에게 맞음 |
| E-Sys + ENET 케이블 | 어려움 | 케이블만 구매 | 모듈 값을 직접 수정. FDL 코딩, FSC 작업 가능 |
| ISTA | 어려움 | 노트북 + ICOM 등 | 소프트웨어 업데이트(I-Step), 진단용 |
| 업체 시공 | - | 항목별 비용 | AA 활성화, FSC 작업은 업체에 맡기는 경우가 많음 |

## 4. 주의사항

- **보증**: 2019년식이면 기본 보증은 대부분 끝났겠지만, BSI 등 연장 보증이 남아 있으면 코딩 이력이 문제 될 수 있다. 코딩 전 원래 값 백업을 해두고, 입고 전 원복하는 사람이 많다.
- **배터리**: 코딩·업데이트 중 전압이 떨어지면 모듈이 벽돌이 될 수 있다. 시동을 끈 상태에서 장시간 작업하면 배터리 충전기(13.5V 이상 유지)를 연결한다.
- **서비스센터 업데이트**: 센터에서 소프트웨어 업데이트를 하면 코딩한 값이 초기화될 수 있다. 다시 코딩하면 된다.
- **FSC 작업**은 실패 시 헤드유닛 기능이 잠길 수 있으므로 백업 없이 하지 않는다.

## 5. 추천 순서

1. 헤드유닛 종류(NBT EVO / MGU)와 현재 I-Step 버전 확인
2. BimmerCode + 어댑터로 "코딩 가능 항목" 스캔 및 전체 백업
3. 편의 코딩(스타트/스톱 기억, 미러 접힘, 주행 중 영상 등)부터 적용
4. AA가 필요하면: MGU → 소프트웨어 업데이트 / NBT EVO → 활성화 업체 또는 MMI 박스 검토
